# Bible-modules-for-eSword
Modules BBLI pour eSword.

Download le module que tu veux, et mets-le dans c:\Program Files (x86)\e-Sword


Nestle1904 est le bien connus texte critique Grec.

Vulgate 405 est la Vulgate de Jérome de 405 CE

Sistine Vulgate est la version du Pape Sixtus V, en 490

Clementine Vulgate est la bible corrigée commandée par le pape Clement VIII en 492, pour corriger les erreurs de Sixtus V.

Les autres titres de bible sont auto-explicatifs. Googles-les pour plus d'infos.
